# Local AI Chatbot using Ollama

## Overview

This project is a local AI-powered chatbot built using Python and Ollama. It allows users to ask questions in natural language and receive responses from a locally hosted Large Language Model (LLM).

## Features

* Natural language question answering
* Local execution using Ollama
* Privacy-focused architecture
* Fast response generation
* Easy-to-use command-line interface

## Technologies Used

* Python
* Ollama
* Large Language Models (LLMs)
* UV Package Manager

## Project Structure

* main.py : Main application file
* pyproject.toml : Project dependencies
* uv.lock : Dependency lock file

## Future Enhancements

* Web interface using Streamlit
* Voice-based interaction
* Document question answering
* Chat history storage
